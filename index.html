How to install
  • Mac: open the downloaded file and drag Hotdog into Applications. The first time, macOS asks whether to open an app from the internet: click Open. Hotdog is signed and checked by Apple.
  • Windows: run the downloaded file. If Windows shows "Windows protected your PC", click More info, then Run anyway.
  • Which Mac do I have? Apple menu → About This Mac. "Chip: Apple M…" is Apple Silicon, "Processor: Intel" is Intel.
  • After that, Hotdog updates itself: open Updates in the app and click Check for updates.
